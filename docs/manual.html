顔マウス 利用マニュアル

「顔マウス」は、Webカメラに映った顔の向きでマウスカーソルを動かし、ウインクでクリックするツールです。手がふさがっているとき、手袋をしているときなどに、マウスに触れずにPCを操作できます。

第1部 利用者向け起動・操作・困ったときの対処。使うだけの方はここだけ読めばOKです 第2部 導入担当者向けPCへのインストール、配布、感度などの調整
第1部

利用者向け

1. 使う前に

  • PCにWebカメラ（ノートPCの内蔵カメラで可）が付いていること
  • カメラの正面、顔全体が映る位置（画面から50cm〜80cm程度）に座ってください
  • 顔が明るく映る環境で使ってください。逆光（背後に窓など）だと認識しにくくなります
  • マスクは外さなくても使えることが多いですが、目と鼻が隠れていると動きません（帽子のつば・前髪・反射の強いメガネにも注意）

2. 起動と終了

起動

プロジェクトフォルダにある start_face_mouse.bat をダブルクリックします（導入担当者がデスクトップにショートカットを用意している場合は、そちらをダブルクリック）。

起動すると、画面の一番上の中央に小さな半透明の表示が出ます。これが出ていれば顔マウスは動いています。

顔マウス：無効（両目2秒で有効）
↑ 画面の一番上の中央に、このように表示されます
上部中央の表示意味
顔マウス：無効（両目2秒で有効）起動直後の状態。カーソルは動かず、クリックもしません
顔マウス：有効顔の向きでカーソルが動き、ウインクでクリックできます
顔マウス：顔が見つかりませんカメラに顔が映っていません。カメラの正面に座り直してください
  • この表示はクリックを邪魔しません（表示の下にあるボタンもそのまま押せます）
  • 表示の後ろに LEFT CLICK や ACTIVATING 1.2s / 2.0s などが一時的に出ることがあります（後述）
黒い画面は閉じないでください 起動すると黒いコンソール画面（文字が流れる画面）も開きます。これを閉じると顔マウスが終了します。邪魔なときは最小化してください。

終了

キーボードで Ctrl + Alt + Q を押します。上部中央の表示が消えれば終了です。

3. 有効にする／無効にする

起動直後は誤操作を防ぐため無効になっています。

有効にする
両目を2秒間閉じる
または Ctrl + Alt + P
無効に戻す
両目を5秒間閉じる
または Ctrl + Alt + P
  • 目を閉じている間、上部中央に ACTIVATING 1.2s / 2.0s（有効にするまでの秒数）や DEACTIVATING 3.0s / 5.0s（無効にするまでの秒数）が表示されます
  • 切り替わると ACTIVATED（有効になった）／DEACTIVATED（無効になった）と表示されます。表示が出たら目を開けてください
  • 普通のまばたきでは切り替わりません
ヒント 席を離れるとき、資料を読むときなどは無効にしておくと安心です。

4. カーソルを動かす

  • 有効にした瞬間の顔の位置が「中心」になり、カーソルは画面中央に移動します
  • そこから顔を左右・上下に向けると、その方向へカーソルが動きます。体ごと動かす必要はありません
  • 正面に戻すとカーソルも画面中央に戻ります
  • 姿勢が変わって操作しにくくなったら、楽な姿勢で正面を向いて Ctrl + Alt + C を押すと、そこが新しい中心になります

5. クリック・スクロールする

左クリック
左目だけを閉じて（0.3秒以上）、1秒以内に開ける
ダブルクリック
左目だけを1秒閉じ続ける
右クリック
右目だけを閉じて（0.3秒以上）、2秒以内に開ける
スクロール
右目だけを2秒閉じ続ける → 顔を上下に向ける
下の「スクロールする」を参照
  • 「左目」「右目」は自分から見た左右です
  • 片目を閉じている間はカーソルが止まるので、狙った位置でクリックできます
  • 片目を閉じている間、上部中央に L-HOLD 0.6s / 1.0s（左目）／R-HOLD 1.2s / 2.0s（右目）のように秒数が出ます。左目は1.0秒でダブルクリック、右目は2.0秒でスクロール保持になります
  • クリックすると上部中央に LEFT CLICK／DOUBLE CLICK／RIGHT CLICK と表示されます
  • 続けてクリックするときは、1秒ほど間を空けてください（連続誤クリック防止のため）

スクロールする（スクロール保持モード）

  1. スクロールしたい画面の上にカーソルを置く
  2. 右目だけを2秒閉じ続ける → 上部中央に SCROLL ON と出たら目を開ける（カーソルはその場で止まります）
  3. 顔を上に向けると上へ、下に向けると下へスクロールします。大きく向けるほど速くなり、正面付近に戻すと止まります
    顔マウス：有効　SCROLL ▼
    ↑ スクロール中は上部中央に向きが表示されます
  4. 終わったらもう一度ウインク（左右どちらの目でも可）→ SCROLL OFF と出て、通常のカーソル操作に戻ります
  • スクロール保持中のウインクは解除だけを行い、クリックはしません
  • 無効にした（両目5秒・Ctrl+Alt+P）場合も、スクロール保持は終了します
  • スクロールの向きは手順2で目を閉じたときの顔の高さが基準です。基準より上か下かでスクロールします
うまくウインクするコツ 閉じる側の目をしっかり閉じ、反対の目は普段どおり開けておくのがコツです。反対の目がつられて細くなると認識されにくくなります。最初は鏡の前で練習すると早く慣れます。

6. キー操作一覧

どのアプリを操作中でも使えます。

キー動作
Ctrl + Alt + P有効／無効の切り替え
Ctrl + Alt + C今の顔の位置を中心に設定し直す
Ctrl + Alt + Wカメラ映像の確認ウィンドウを表示／非表示
Ctrl + Alt + Q終了

7. 緊急停止

カーソルが勝手に動き回るなど、思いどおりに操作できなくなったときは次のどれかで止めます。

  1. Ctrl + Alt + Q を押す（終了）
  2. 両目を5秒閉じる、または Ctrl + Alt + P を押す（無効にする）
  3. 手で本物のマウスを、画面の四隅のどこかへ勢いよく動かす（安全装置が働き、顔マウスが強制終了します）

8. 困ったとき

症状対処
上部中央の表示が出ない顔マウスが起動していません。もう一度起動してください。黒いコンソール画面にエラーが出ていれば、その内容を導入担当者に伝えてください
「顔が見つかりません」のままカメラの正面に座る／部屋を明るくする／カメラのシャッター・カバーを開ける。Ctrl+Alt+W で映像を見て、顔が映っているか確認してください
両目を閉じても有効にならない目をしっかり閉じて2秒待ってください。それでも駄目なら導入担当者に感度調整を依頼してください（第2部 5章）
カーソルが動きすぎる／足りない導入担当者に感度調整を依頼してください
カーソルが端まで届かない顔をもう少し大きく向けるか、Ctrl+Alt+C で中心を合わせ直してください
カーソルが小刻みに震える顔を明るく照らす、カメラを固定する。改善しなければ導入担当者に相談
ウインクしてもクリックされない反対の目を大きめに開けたまま、閉じる目をしっかり閉じてください。0.3秒以上閉じる必要があります
スクロールが止まらない／勝手に流れる顔を正面（スクロールを始めたときの高さ）に戻すと止まります。ウインクで解除してください
意図せずクリックされる使わないときは無効にしてください。頻発する場合は導入担当者に相談
「カメラを開けませんでした」と出て終了する他のアプリ（Teams・Zoom など）がカメラを使っていないか確認し、閉じてから起動し直してください
突然終了した（「FAILSAFE が発動しました」）マウスが画面の四隅に移動したため安全装置で止まりました。起動し直してください
第2部

導入担当者向け

1. 動作環境

OSWindows 11（グローバルホットキーと上部の状態表示は Windows 専用）
Python3.12（uv が管理）
主なパッケージmediapipe（顔検出）、OpenCV（カメラ）、pyautogui（マウス操作）、tkinter（状態表示。Python標準）
機材Webカメラ（640×480 以上）
必要ファイルmodels/face_landmarker.task（顔検出モデル。約3.6MB）

2. インストール（ネットにつながるPC）

  1. uv をインストール（未導入の場合）。PowerShell で次を実行します 
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  2. プロジェクトフォルダを用意します（例：C:\Tools\eyetracking-ui）。GitHub の maeda0601/eyetracking-ui から git clone するか、「Code」→「Download ZIP」で取得して展開します。他のPCからコピーする場合、.venv フォルダはコピー不要です
  3. プロジェクトフォルダで環境を作成（Python 3.12 も必要に応じて自動で入ります） 
    uv sync
  4. 顔検出モデルを取得（約3.6MB。models\face_landmarker.task に保存されます。start_face_mouse.bat の初回起動時にも自動で取得されます） 
    uv run scripts/download_model.py
    社内プロキシ等でダウンロードできない場合は、次のURLをブラウザで開いて models\face_landmarker.task に保存してください
    https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
  5. 起動確認：start_face_mouse.bat をダブルクリック（またはコマンド uv run scripts/face_mouse.py）
    画面上部中央に 顔マウス：無効（両目2秒で有効） が出れば成功です。Ctrl+Alt+Q で終了します

3. インストール（ネットにつながらないPC）

ネットにつながるPC（Python 3.12 があるもの）で準備し、USBメモリなどで持ち込みます。

準備（ネットにつながるPC）

  1. uv の単体実行ファイル（uv.exe）を入手する（GitHub の astral-sh/uv のリリースページから uv-x86_64-pc-windows-msvc.zip）
  2. Python 3.12 のインストーラーを入手する（python.org）
  3. プロジェクトフォルダで、依存パッケージを wheel 形式でまとめる 
    py -3.12 -m pip wheel -r requirements.txt -w wheels
    ※pyautogui などは wheel が配布されていないため、pip download ではなく pip wheel を使います
  4. 顔検出モデルを取得する（py -3.12 scripts\download_model.py。models\face_landmarker.task に保存されます）
  5. 持ち込むもの：プロジェクトフォルダ一式（wheels と models\face_landmarker.task を含む、.venv は除く）、uv.exe、Python 3.12 インストーラー

インストール（持ち込み先PC）

  1. Python 3.12 をインストールする（「tcl/tk and IDLE」にチェックが入ったまま＝既定のままにしてください。上部の状態表示に必要です）
  2. uv.exe を任意のフォルダに置く（例：C:\Tools\uv\uv.exe。PATH を通すと便利です）
  3. プロジェクトフォルダで次を実行する 
    uv venv --python 3.12
uv pip install --no-index --find-links wheels -r requirements.txt
  4. start_face_mouse.bat をダブルクリックして起動確認します（bat は .venv の Python を直接使うため、オフラインでも動きます）

4. 利用者への配布のヒント

  • 起動は start_face_mouse.bat（プロジェクトフォルダ直下）を使います。動作は次のとおりです
    • .venv が無ければ uv sync で作成（ネット接続と uv が必要）してから起動
    • .venv があればその Python で直接起動（オフラインでも動く）
    • エラーで止まったときは画面を閉じずにメッセージを表示したまま待つので、利用者から内容を聞き取れます
  • start_face_mouse.bat を右クリック →「その他のオプションを確認」→「ショートカットの作成」で作ったショートカットをデスクトップに置くと便利です。ショートカットのプロパティで「実行時の大きさ」を「最小化」にすると、黒い画面が邪魔になりません
  • パッケージ構成を更新した（pyproject.toml が変わった）ときは、uv sync を実行し直してください（bat は .venv があると同期を行いません）
  • 初回はカメラの使用許可を確認してください：Windows の「設定」→「プライバシーとセキュリティ」→「カメラ」で、デスクトップアプリがカメラにアクセスできるようにするがオンになっていること
  • 第1部を印刷して手元に置いてもらうと、最初の練習がスムーズです（このページはブラウザの印刷機能で、第2部が別ページになるよう印刷できます）

5. 感度・しきい値の調整

調整は scripts\face_mouse.py の冒頭にある定数（大文字の名前）を書き換えて行います。書き換えた後は顔マウスを起動し直してください。

まず確認ウィンドウで数値を見る

Ctrl+Alt+W で確認ウィンドウを出すと、左上に L-EAR／R-EAR（左目・右目の開き具合）が表示されます。

  • 目を開けているときの値と、閉じたときの値をメモします（目安：開けて約0.22、閉じて約0.09）
  • 閉じたときに赤字になれば「閉じている」と判定されています

症状別の調整項目

症状調整する定数方向
カーソルが動きすぎる／足りないSENSITIVITY_X（横）／SENSITIVITY_Y（縦）動きすぎ→小さく、足りない→大きく
カーソルが震えるSMOOTHING_ALPHA／DEAD_ZONE_PXSMOOTHING_ALPHA を小さく、DEAD_ZONE_PX を大きく（反応は少し遅くなります）
目を閉じても閉じた判定にならないEAR_CLOSED_THRESHOLD（既定 0.14）閉じたときの EAR より少し大きい値に上げる
目を開けているのに閉じた判定になるEAR_CLOSED_THRESHOLD開けたときの EAR より十分小さい値に下げる
ウインクが途中で途切れるWINK_EAR_DIFF／WINK_KEEP_EAR_DIFF小さくする
誤クリックが多いWINK_HOLD_SEC／CLICK_COOLDOWN_SEC長くする
ダブルクリックまでの時間を変えたいDOUBLE_CLICK_HOLD_SEC（既定 1.0秒）好みで
スクロール保持を始めるまでの時間を変えたいSCROLL_HOLD_SEC（既定 2.0秒）好みで
スクロールが速すぎる／遅すぎるSCROLL_SPEED_GAIN（既定 200）／SCROLL_MAX_NOTCHES_PER_SEC（上限。既定 20段/秒）速すぎ→小さく、遅すぎ→大きく
正面を向いているのにスクロールが止まらないSCROLL_DEAD_ZONE（既定 0.015）大きくする
有効／無効の切り替え時間を変えたいACTIVATE_HOLD_SEC（既定 2秒）／DEACTIVATE_HOLD_SEC（既定 5秒）好みで
起動直後から有効にしたいSTART_PAUSEDFalse にする
上部の表示を薄く／濃くしたいOVERLAY_ALPHA（既定 0.55）薄く→小さく、濃く→大きく
上部の表示を消したいSHOW_STATUS_OVERLAYFalse にする
起動時から確認ウィンドウを出したいSHOW_WINDOW_ON_STARTTrue にする
別のカメラを使いたいCAMERA_INDEX外付けカメラは 1 など
ホットキーが他のアプリと重なるHOTKEY_ACTIONS割り当てるキーを変更する
安全装置は無効にしないでください pyautogui.FAILSAFE を False にすると、マウスを画面の四隅に動かして緊急停止する手段がなくなります。

6. エラーメッセージと対処

起動時やエラー時は、黒いコンソール画面に日本語でメッセージが出ます。

メッセージ原因と対処
モデルファイルが見つかりませんmodels\face_landmarker.task が無い。uv run scripts/download_model.py で取得する（第2部 2章の手順4）
カメラ（番号 0）を開けませんでしたカメラ未接続／他アプリが使用中／プライバシー設定でブロック。外付けカメラなら CAMERA_INDEX を変更
カメラから映像を取得できませんでした使用中にカメラが外れた。接続を確認して起動し直す
FAILSAFE が発動しましたマウスが画面の四隅に移動したため安全停止した。起動し直す
tkinter が使えないため、画面上部の状態表示は行いませんPython に tkinter が入っていない。Python 3.12 を既定設定（tcl/tk 付き）で入れ直す
ModuleNotFoundErrorパッケージが入っていない。uv sync（オフラインなら第2部 3章）をやり直す
